Differentiable neuron simulation · Rust

A real neuron, trained by gradient descent.

openbrain simulates reconstructed neurons with the full cable equations and computes exact gradients through them. On a laptop CPU, a rat CA1 pyramidal cell learns XOR in 34–98 Adam steps (9–23 seconds), trained directly rather than through a surrogate network.

02 · Result

It responds to one input, not to both.

Inputs A and B each drive AMPA, NMDA and GABAA synapses at 16 dendritic sites. Gradient descent tunes all 96 weights until the average soma voltage is higher when exactly one input is active than when none or both are. Over six random seeds, training took 34–98 steps and 9–23 CPU-seconds.

one input (10, 01) both inputs (11) no input (00)
How the readout works

Scored on the mean over 10–60 ms

When only one input fires, the soma depolarises and stays up. When both fire, the trained inhibition of each input lands on the other’s excitation, and the response falls back sooner and dips below rest.

The loss is a softplus on every true/false gap, with exact gradients from a discrete adjoint: one backward Hines solve per time step, about the cost of a second simulation.

gap ≥ 1 mV → solved · checked against finite differences to 1e-6

03 · Control

Do the dendrites matter? Partly.

I expected a point neuron to fail at XOR, but it doesn’t: over the 60 ms window, two fast inhibitory dips add up while the slower excitation saturates. So instead of pass or fail, the control compares the best margin each configuration reaches in 300 steps, with the same 96 synapses in every case.

Finding

Placement beats the soma control 8 / 8

Moving the same synapses onto dendrites always widens the margin over putting them on the soma: 1.27–2.81 mV against 1.19 mV.

A single-compartment neuron with the same membrane area reaches 1.65 mV, and 5 of 8 placements beat it. So where the synapses sit matters about as much as whether the cell has dendrites at all.

The next phase tests this across 1,000+ real neurons.

04 · Benchmark

Same cell, same inputs, three simulators.

openbrain’s 4,229 cylinders are exported verbatim into NEURON and Jaxley, then driven by the same current pulses at 16 sites for 60 ms at dt = 0.1 ms. Accuracy is measured against NEURON with 9 segments per cylinder and dt = 0.0025 ms.

The gradients agree with Jaxley to 0.2%. NEURON is twice as accurate at equal dt; openbrain currently applies each input one time step early, and fixing that is next. Jaxley is built for GPUs, and this test ran on CPU only.

05 · Method

Cable solver, synapses and gradients, all in Rust.

Each part was written against a test first: published HH behaviour, cable convergence, supralinear NMDA summation, and adjoint gradients against finite differences for every synapse type.

01

Cable on a real tree

Each SWC point becomes a cylinder. Backward Euler turns every time step into a tree-structured linear system, solved in O(n) by the Hines method.

02

Conductance synapses

AMPA, NMDA with its Mg²⁺ block, and GABAA enter as conductances with double-exponential kinetics. The block uses the previous step’s voltage, so each step stays one linear solve.

g(t) = w · s(t) · B(V) B(V) = 1 / (1 + [Mg]/3.57 · e^(−0.062 V))
03

Exact adjoint gradients

The adjoint runs the simulation backwards in time. Because the system matrix is symmetric, each backward step is another Hines solve, so the gradient for every weight together costs about one extra simulation.

A(vⁿ) λⁿ = ∂L/∂vⁿ⁺¹ + … ∂L/∂w_s = Σₙ λⁿ_c · s(tₙ) · B · (E − vⁿ⁺¹)
