A real neuron, trained by gradient descent.

openbrain simulates reconstructed neurons with the full cable equations and computes exact gradients through them. Here, a rat CA1 pyramidal cell learns XOR in 34 steps and 3 seconds on a laptop CPU. No surrogate network.

01 · Result

One input fires it. Both inputs don’t.

Inputs A and B each drive AMPA, NMDA and GABAA synapses at 16 dendritic sites. Gradient descent tunes all 96 weights until the average soma voltage is higher for exactly one input than for none or both. The cell computes XOR. Across six random seeds it takes 34–98 steps and 9–23 CPU-seconds.

one input (10, 01) both inputs (11) no input (00)
How the readout works

Scored on the mean over 10–60 ms

When only one input fires, the soma depolarises and stays up. When both fire, the trained inhibition of each input lands on the other’s excitation, and the response falls back sooner and dips below rest.

The loss is a softplus on every true/false gap, with exact gradients from a discrete adjoint: one backward Hines solve per time step, about the cost of a second simulation.

gap ≥ 1 mV → solved · checked against finite differences to 1e-6

02 · Control

Do the dendrites matter? Partly. Here is the honest answer.

I expected a point neuron to fail at XOR. It didn’t: over time, two fast inhibitory dips add up while slower excitation saturates. So the control measures the best margin each configuration reaches in 300 steps, with the same 96 synapses everywhere.

Finding

Placement beats the soma control 8 / 8

Moving the same synapses onto dendrites always widens the margin over putting them on the soma: 1.27–2.81 mV against 1.19 mV.

A single-compartment neuron with the same membrane area reaches 1.65 mV, and 5 of 8 placements beat it. Where synapses sit matters about as much as having dendrites at all.

That is the question the next phase scales up: capacity across 1,000+ real neurons.

03 · Benchmark

Same cell, same inputs, three simulators.

openbrain’s 4,229 cylinders are exported verbatim into NEURON and Jaxley, then driven by the same current pulses at 16 sites for 60 ms at dt = 0.1 ms. Accuracy is measured against NEURON with 9 segments per cylinder and dt = 0.0025 ms.

The gradients agree with Jaxley to 0.2%. NEURON is twice as accurate at equal dt; openbrain applies each input one step early, which is the next fix. Jaxley is built for GPUs, which this CPU test does not cover.

04 · Method

Three pieces, all in Rust.

Every piece is held to a test first: published HH behaviour, cable convergence, supralinear NMDA summation, and adjoint gradients against finite differences for every synapse type.

01

Cable on a real tree

Each SWC point becomes a cylinder. Backward Euler turns every time step into a tree-structured linear system, solved in O(n) by the Hines method.

02

Conductance synapses

AMPA, NMDA with its Mg²⁺ block, and GABAA enter as conductances with double-exponential kinetics. The block uses the previous step’s voltage, so each step stays one linear solve.

g(t) = w · s(t) · B(V) B(V) = 1 / (1 + [Mg]/3.57 · e^(−0.062 V))
03

Exact adjoint gradients

The adjoint walks the simulation backwards. The system is symmetric, so each backward step is again one Hines solve: about two simulations’ cost for every weight’s gradient at once.

A(vⁿ) λⁿ = ∂L/∂vⁿ⁺¹ + … ∂L/∂w_s = Σₙ λⁿ_c · s(tₙ) · B · (E − vⁿ⁺¹)
